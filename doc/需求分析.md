# 需求分析 · 航拍 OSD 参数提取

> 2026-11-22 ｜ 实习方出题：制作一个演示程序，从含参数显示的航拍图或航拍视频中提取文字（航向角、高度、经纬度），实时输出。

## 1. 任务定义

- **输入**：含 OSD（On-Screen Display）参数叠加显示的航拍图片或视频——航向角、高度、经纬度以文字形式"画"在画面上
- **输出**：三个参数的数值，随画面实时更新，**以文本形式输出**（终端打印 + 画面叠加显示；当前阶段不做语音播报）

## 2. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 图片单帧提取 | 输入一张航拍图，输出一次三参数结果 |
| F2 | 视频实时提取 | 输入视频文件，循环处理，参数随画面持续更新 |
| F3 | 三参数解析 | 航向角（°）、高度（m/ft）、经纬度（度分秒/十进制两种格式兼容） |
| F4 | 文本输出 | 终端实时打印；提取结果叠加显示在画面上（半透明数值条），便于肉眼对照 |
| F5 | 抗干扰 | 画面复杂背景、OSD 数字闪烁不影响输出稳定 |

## 3. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| N1 | 实时性 | 采样率 ≥ 2 FPS；数值更新延迟 ≤ 1 s |
| N2 | 正确性 | 演示素材上三参数全程读对（OCR + 解析双环节保证） |
| N3 | 稳定性 | 数值去抖（连续 3 次一致才更新），不因 OSD 闪烁跳变 |
| N4 | 通用性 | 不绑定单一厂商格式：关键词与格式特征双保险匹配；经纬度两格式、米/英尺换算 |
| N5 | 环境约束 | Windows、Python、纯 CPU、离线可用 |

## 4. 使用场景（演示现场）

面试官播放一段 30 s 航拍素材，程序同步输出三参数文本并叠加回画面——肉眼可对照"画面显示值 = 程序读出的值"。要求开箱即用、不依赖网络、一次标定后全自动。

## 5. 验收标准

1. 图片模式：单图三参数全部正确
2. 视频模式：30 s 素材全程参数正确、无跳变、延迟 < 1 s
3. 标定一次后无人干预运行
4. 输出可读：终端日志 + 画面叠加双通道

## 6. 边界与不做什么

- 不做：语音播报（本阶段）、移动端、GPU 加速、多路视频
- 经纬度只做解析与换算，不做地图可视化
- 若素材带大疆 .SRT 字幕文件，元数据直读作为对比验证手段（见《方案选择》）
