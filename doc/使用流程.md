# 使用流程 · OCR_reader

## 第 0 步：准备素材

1. 素材放进 `samples\`
2. **文件名必须是英文/数字**（cv2 不支持中文路径），中文名先复制改名为 `demo.mp4` 之类
3. `.m4s` 分片若打不开，先用 ffmpeg 转封装：`ffmpeg -i in.m4s -c copy out.mp4`

## 第 1 步：标注 ROI（程序 1）

双击 `1-ROI标注工具.bat`

1. **打开视频/图片**（找一帧 OSD 信息显示齐全的画面）
2. 点 **预识别当前帧**：全图 OCR，所有文字区域画红框——这是定位 OSD 的雷达。视频可点"自动采样预识别"，对 25%/50%/75% 三帧扫描并汇总
3. 右侧选好标签（航向角 / 高度 / 经度 / 纬度 / 经纬度 / 自定义），在画面上**按住左键拖拽画框**
4. 对每个参数重复 3：框住数值所在区域
5. 点 **保存 ROI 模板** → 生成 `roi_template.json` + `roi_template_preview.jpg`

标注建议：

- 框比文字**大一圈**（宽高多留 10~20%），数值位数变化（99.9→100.1）时不会切字
- 经纬度如果是一整段，框一个整体；如果是分开的两段，框两个（经度、纬度）
- 框内尽量只含参数本身，不要把旁边图标/其他数字框进来

## 第 2 步：实时提取（程序 2）

双击 `2-实时提取UI.bat`

1. **打开视频**（与标注素材同分辨率最佳；不同分辨率会自动按比例缩放框）
2. **载入模板**：选 `roi_template.json`
3. 点 **开始**

右侧参数面板三列：

| 列 | 含义 |
|---|---|
| 参数 | 模板里的标签名 |
| 实时值 | 本次 OCR 直接读出（灰） |
| 确认值 | 连续 3 次读一致才显示（绿），防 OSD 闪烁 |

左侧画面叠加：蓝框 = ROI 区域，框上白字 = 当前实时值，框下绿字 = 确认值。

可调项：OCR 间隔（默认 0.5 s）、循环播放、显示/隐藏 ROI 框。

## 第 3 步：观察与迭代

| 现象 | 处理 |
|---|---|
| 数值读错/读不全 | 回程序 1 调整框的位置和大小，重存模板 |
| ° 被读成 6（如 123.4°→123.46） | 已知风险，频发则加解析纠错规则（找 Claude） |
| 确认值一直不出来 | 数值闪烁频繁 → 调大 OCR 间隔，或框大一点 |
| 视频卡顿 | OCR 间隔调大（1 s），CPU 占用量会明显下降 |

## 文件清单

```
OCR_reader/
├─ 1-ROI标注工具.bat      # 程序 1 启动器（固定 Miniconda python）
├─ 2-实时提取UI.bat        # 程序 2 启动器
├─ roi_template.json       # 模板（程序 1 保存，程序 2 载入）
├─ roi_template_preview.jpg# 模板预览图
├─ requirements.txt
├─ samples/                # 素材（英文文件名）
├─ doc/                    # 需求分析 / 方案选择 / 使用流程
└─ src/                    # 源码
```
